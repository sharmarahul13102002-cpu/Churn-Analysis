# 📊 Customer Churn Analysis & Prediction

## 📌 Project Overview

Customer Churn Analysis & Prediction is an end-to-end Data Analytics and Machine Learning project that analyzes customer behavior, identifies the key factors influencing customer churn, and predicts customers who are likely to leave a service. The project combines SQL Server, Power BI, and Python to build an interactive dashboard and a predictive model that helps businesses improve customer retention strategies.

---

## 🎯 Project Objectives

- Analyze customer demographics and service usage.
- Identify factors contributing to customer churn.
- Build interactive dashboards for business insights.
- Predict potential churn customers using Machine Learning.
- Support customer retention through data-driven decision-making.
